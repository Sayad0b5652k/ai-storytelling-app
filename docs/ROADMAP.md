# Roadmap

## Phase 0 — Bootstrap

- Repository and collaboration contract
- Product architecture and schemas
- CI, linting and test baseline

## Phase 1 — Thin vertical slice

- Manual topic input
- Structured story fixture/generation adapter
- Three sample episodes with scenes
- Novel and comic presentation
- Reusable character/background assets
- Local save, resume and quiz
- Mughal Empire sample content

## Phase 2 — Material mode

- PDF import and local preview
- Zoom, thumbnails and page navigation
- Text-PDF extraction
- TOC/headings detection
- Chapter and page-range selection
- OCR fallback for scanned PDFs
- Extracted-text preview and correction
- Source-page references in generated stories

## Phase 3 — General learning product

- Research and hybrid modes
- Language, length and difficulty controls
- Episode continuation and editing
- Summaries, timelines, facts and revision mode
- Search, bookmarks, reading history and progress
- Dark/light themes and text size controls

## Phase 4 — Scene director and asset system

- Asset catalog, tagging and licensing metadata
- Character expressions/poses and backgrounds
- Rule-based scene director
- Maps, SVG illustrations and transitions
- Optional custom image generation with caching

## Phase 5 — Expansion

- Read-aloud narration
- More languages and narration voices
- Interactive choices
- PDF export and sharing
- Community asset/template workflows
